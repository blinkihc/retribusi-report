## Laporan Retribusi

### Melihat Daftar
1. Klik **Laporan Retribusi** di sidebar
2. Gunakan filter untuk menyaring data
3. Klik header kolom untuk sorting

### Filter
- **OPD**: Filter berdasarkan instansi
- **Jenis Retribusi**: Filter berdasarkan jenis
- **Tanggal**: Rentang tanggal setor
- **Status**: Draft/Submitted/Approved

### Membuat Laporan Baru
1. Klik tombol **+ Tambah Laporan**
2. Isi form:
   - Pilih OPD
   - Pilih Jenis Retribusi
   - Masukkan Jumlah
   - Pilih Tanggal Setor
   - Upload bukti (opsional)
3. Klik **Simpan**

### Edit/Hapus Laporan
- **Edit**: Klik ikon pensil atau swipe kiri (mobile)
- **Hapus**: Klik ikon sampah atau swipe kanan (mobile)

## Rekap & Laporan

### Generate Rekap
1. Pilih periode tanggal
2. Pilih jenis rekap (OPD/Kategori/Jenis)
3. Klik **Generate**

### Export Excel
1. Klik tombol **Export Excel**
2. File akan terdownload otomatis

## Tips & Troubleshooting

### Koneksi Bermasalah
- Periksa koneksi internet
- Refresh halaman
- Coba login ulang

### Data Tidak Muncul
- Periksa filter yang aktif
- Klik **Reset Filter**

### Butuh Bantuan?
Hubungi administrator sistem.
